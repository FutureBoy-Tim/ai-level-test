# 나의 AI 활용도 진단하기 · 2026 최신판

수업 현장에서 수강생이 스마트폰으로 QR을 찍어 바로 접속하는 AI 활용도 자가진단 페이지입니다.

- 배포 주소: <https://futureboy-tim.github.io/ai-level-test/>
- 수업용 자료 · 미래소년 AI 마케팅 연구소

## 구성

| 영역 | 설명 |
|---|---|
| 01 프롬프트 복사 | 공통(추천) / ChatGPT용 / Claude용 / Gemini용 / AI 청문회(크로스 체크)용 5개 탭. 버튼 한 번으로 클립보드 복사 + 토스트 안내 |
| 02 1분 자가진단 | 5문항(질문력·검증력·맥락력·연결력·자동화력) → Lv1~Lv5 레벨, AI 유형 별명, 5대 전투력 레이더·막대 차트, 구독료 본전 팩폭, 당장 바꿀 습관, 다음 단계 팁. 결과를 텍스트로 복사해 단톡방 공유 |
| 03 레벨 기준 | Lv1 검색기 ~ Lv5 설계자 기준표 |

## 구조

```
index.html   # 단일 파일 (외부 라이브러리·폰트 없음, 오프라인에서도 동작)
.nojekyll    # GitHub Pages가 파일을 그대로 서빙하도록
```

프레임워크·빌드 없이 `index.html` 하나로 동작합니다. 수정은 이 파일만 고치면 됩니다.

## 진단 기준 (2026 최신판)

- 레벨: Lv1 검색기 · Lv2 질문자 · Lv3 지시자 · Lv4 협업자 · Lv5 설계자 (수업 슬라이드와 같은 명칭)
- 5대 전투력 스탯(각 100점): 질문력 · 맥락력 · 검증력 · 연결력 · 자동화력
- 출력: 레벨 + 근거, 스탯 점수, AI 유형 별명, 구독료 본전 팩폭 1줄, 당장 바꿀 습관 1가지, 다음 단계 팁 3가지
- 기록이 부족하면 AI가 5문항 인터뷰로 대체(fallback)
